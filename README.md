# Python Piscine

42 School – Python for Data Science Piscine

This repository contains all the work completed during the **Python Piscine** at 42.  
The piscine focuses on building a solid foundation in Python for data science through progressive modules covering core language features, numerical computing, data analysis, object-oriented programming and advanced Python concepts.

---

## Modules

| Module | Name | Technical Focus |
|--------|------|-----------------|
| **00** | Starting | Python fundamentals: lists, tuples, sets, dictionaries, string formatting, type checking, filters, Morse code, progress bars and packaging |
| **01** | Array | Numerical computing with NumPy: BMI calculation, 2D array slicing, image loading, zoom, rotation and basic image filters |
| **02** | DataTable | Data analysis with Pandas: CSV loading, data cleaning, life expectancy visualization, population comparison and income vs life expectancy projections |
| **03** | OOP | Object-Oriented Programming: abstract base classes, inheritance, method overriding, diamond problem (multiple inheritance) and operator overloading |
| **04** | DOD | Data Oriented Design: closures, nested functions, `nonlocal`, higher-order functions, decorators and dataclasses |

## How to run

Most exercises include a `tester.py` file.

```bash
cd Module_X/exYY
python3.10 tester.py
```

Some exercises can also be executed directly:

```bash
python3.10 script_name.py
```

Always prefer running the provided tester when available, as it matches the expected evaluation format.
